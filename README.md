## Лабораторная работа 1

Решение уравнения `A*x^4 + B*x^2 + C = 0` в трех парадигмах.

Требуется Python 3.10 или новее. Дополнительные библиотеки не нужны.

Из корня репозитория:

```console
python lab1/procedural.py 1 -5 4
python lab1/oop.py 1 -5 4
python lab1/functional.py 1 -5 4
```

Ожидаемые корни: `-2; -1; 1; 2`, дискриминант: `9`.
Без аргументов коэффициенты вводятся с клавиатуры. Можно передать часть
коэффициентов; недостающие программа запросит. Неверное значение повторно
запрашивается, остальные аргументы сохраняются. Дробная часть записывается
через точку. Значения `nan` и `inf` отклоняются.

Каждый файл запускается отдельно; `common.py` должен находиться рядом.
Вычисления выполняются стандартными числами `float` и рассчитаны на обычные
учебные коэффициенты, без экстремально больших или малых значений.
