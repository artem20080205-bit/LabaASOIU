# Рубежный контроль 2 — рефакторинг варианта 14В

Логика РК-1 разделена на классы данных (`models.py`), демонстрационные
данные (`data.py`), чистые функции запросов (`queries.py`) и консольную
оболочку (`main.py`). Функции получают данные через параметры и возвращают
результат без печати и изменения входных списков.

Python 3.10+, внешние библиотеки не нужны. Из корня репозитория:

```console
python rk2/main.py
python -m unittest discover -s rk2 -p "test_*.py" -v
```

В `test_queries.py` ровно три тестовых метода, по одному на каждый запрос.
Используется стандартный фреймворк `unittest`. Внутри тестов проверяются
основные результаты и пустые входные данные. Данные тестов отличаются от
демонстрационных: проверяются фильтрация, вычисление минимума, исключение
пустой библиотеки, сортировка и несколько библиотек у одного диска.

Тесты проверялись также на заведомо неверных реализациях: отключенная
фильтрация В1, `max` вместо `min` в В2, обратная сортировка В3. На каждом
из этих дефектов соответствующий тест должен завершаться с ошибкой.

Фактические результаты: `execution.txt`. Отчет: `report.docx`, `report.pdf`.
