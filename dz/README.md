# Домашнее задание — консольный список задач на Go

Летуновский Артемий Алексеевич, ИУ5-31Б.

Проект демонстрирует структуры, срезы, функции, циклы `range`, `switch`,
пакеты, обработку ошибок через `error`, интерфейс `io.Writer` и работу с JSON.
Используется только стандартная библиотека. Требуется Go 1.22 или новее.

## Сборка и запуск

Установите Go с https://go.dev/dl/ и откройте терминал в папке `dz`:

```console
go version
go test -v ./...
go build -o tasker.exe .
./tasker.exe add "Изучить Go"
./tasker.exe add "Подготовить домашнее задание"
./tasker.exe list
./tasker.exe done 1
./tasker.exe stats
```

На Linux/macOS можно собрать `go build -o tasker .` и запускать `./tasker`.
Другой вариант без отдельной сборки: `go run . list`.

Задачи сохраняются в `tasks.json` в текущей папке. Можно указать другой файл:
`go run . -file demo.json list`. Флаг `-file` всегда ставится перед командой.
Команда `done` помечает задачу выполненной; повторная отметка допустима.
Ошибки выводятся в stderr, процесс завершается с кодом 1. Поврежденный JSON
не перезаписывается. Проект рассчитан на последовательный запуск одного
пользователя; параллельное редактирование файла не поддерживается.

## Состав

- `main.go` — программа с поясняющими комментариями;
- `main_test.go` — четыре автоматических теста;
- `execution.txt` — фактические результаты сборки, тестов и примеров;
- `report.docx` и `report.pdf` — отчет с кодом и примерами выполнения.
