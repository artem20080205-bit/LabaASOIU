# Рубежный контроль 1 — вариант 14В

Предметная область: CD-диск и библиотека CD-дисков.
Количественный признак диска — длительность в минутах.

Запуск из корня репозитория, Python 3.10+:

```console
python rk1/main.py
```

Запросы варианта В адаптированы к предметной области:

1. **В1**: диски, название которых начинается с кириллической «А», и их
   библиотеки; используется связь один-ко-многим.
2. **В2**: непустые библиотеки с минимальной длительностью диска в каждой,
   по возрастанию минимума; используется связь один-ко-многим.
3. **В3**: все пары диск–библиотека по связи многие-ко-многим,
   с сортировкой по названию диска. При одинаковом названии — по библиотеке.

Есть 5 дисков, 3 библиотеки и 7 связей многие-ко-многим.
Один диск может быть связан с несколькими библиотеками и наоборот.
`CD.library_id` используется только в запросах В1 и В2;
в В3 используются записи `CDLibrary`.

Фактический вывод: `execution.txt`. Отчет: `report.docx`, `report.pdf`.
