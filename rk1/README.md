# Рубежный контроль 1 — вариант 14А

Предметная область: CD-диск и библиотека CD-дисков.
Количественный признак диска — длительность в минутах.

Запуск из корня репозитория, Python 3.10+:

```console
python rk1/main.py
```

Запросы варианта А адаптированы к предметной области:

1. **А1**: все связанные диски и библиотеки по связи один-ко-многим,
   отсортированные по названию библиотеки.
2. **А2**: библиотеки с суммарной длительностью дисков в каждой,
   по убыванию суммы; используется связь один-ко-многим.
   Для пустой библиотеки сумма равна нулю.
3. **А3**: библиотеки, в названии которых присутствует слово «библиотека»,
   и списки их дисков по связи многие-ко-многим.
   Поиск выполняется без учета регистра. Слову «отдел» из исходного
   примера задания соответствует слово «библиотека».

Есть 5 дисков, 3 библиотеки и 7 связей многие-ко-многим.
Один диск может быть связан с несколькими библиотеками и наоборот.
`CD.library_id` используется только в запросах А1 и А2;
в А3 используются записи `CDLibrary`.

Ожидаемые суммы длительностей: Городская библиотека CD — 119 минут,
Архивная библиотека CD — 84 минуты, Фонотека — 42 минуты.

Фактический вывод: `execution.txt`. Отчет: `report.docx`, `report.pdf`.
